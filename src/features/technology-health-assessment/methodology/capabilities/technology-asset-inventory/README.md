# Technology Asset Inventory

This capability evaluates whether the business can identify, assign ownership to, and review the technology it depends on.

Primary report category:
- Technology Operations

Secondary relationships:
- Cybersecurity

Readiness: Pilot. This is a foundational capability for recovery, security, vendor, and modernization decisions. It covers environment-wide visibility; application, infrastructure, vendor, and data inventories remain separate capabilities. Unknown answers create visibility findings and do not assert that assets are absent.
