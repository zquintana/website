# Critical Data Inventory

This capability evaluates whether the business can identify, assign ownership to, and review the data it must protect and recover.

Primary report category:
- Governance and Risk Management

Secondary relationships:
- Cybersecurity

Readiness: Pilot. This capability covers data visibility and ownership. Data classification, access control, retention, backup coverage, and loss prevention remain separate capabilities. Unknown answers create visibility findings and do not assert that critical data is absent.
