# Identity Inventory

This capability evaluates whether the business can identify and assign ownership to the human and non-human identities that can access important systems.

Primary report category:
- Identity and Access Management

Secondary relationships:
- Cybersecurity

Readiness: Pilot. This capability covers visibility and ownership. Identity Lifecycle Management covers joiner, mover, and leaver processes; Privileged Access Management covers administrative safeguards. Unknown answers create visibility findings and do not assert that identities are unauthorized.
